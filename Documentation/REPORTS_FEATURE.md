# Reports Feature

## Overview
A comprehensive reports page has been created to visualize business data with charts and statistics.

## Features

### Statistics Cards
- **Total Repairs**: Shows the total number of repair orders
- **Total Revenue**: Displays total income from all repairs
- **Average Repair Time**: Shows average days from received to delivered
- **Completion Rate**: Percentage of completed/delivered repairs

### Charts

1. **Repairs by Status** (Doughnut Chart)
   - Visual breakdown of repairs by their current status
   - Color-coded for easy identification

2. **Repairs by Type** (Bar Chart)
   - Shows quantity of each repair type
   - Helps identify most common repair services

3. **Revenue by Repair Type** (Bar Chart)
   - Displays income generated by each repair type
   - Useful for identifying most profitable services

4. **Monthly Repairs Trend** (Line Chart)
   - Shows repair volume over the last 6 months
   - Helps identify seasonal trends

## Technology
- **Chart.js**: Used for rendering all charts
- **Angular 18**: Standalone components
- **Responsive Design**: Works on desktop and mobile devices

## Access
- Available to Administrator and Receptionist roles
- Route: `/reports`
- Accessible via the main navigation menu and dashboard
